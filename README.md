Personal portfolio for Tobias / Guanyi Du: https://legatia.github.io/

## Preview

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Open http://127.0.0.1:8765. GitHub Pages publishes the root of `main`.
