01

Rust · Virtual machines · Zcash

Zyn

A reusable execution layer for Zcash applications.

I built a microchain runtime that separates application logic from sequencing, checkpoints, settlement and recovery. Deterministic state transitions, Merkle commitments and signed intents give different applications the same execution foundation.

Engineering notes

Conformance checks cover replay, serialization and value conservation. The workspace also includes swap, wallet and marketplace applications.

02

Go · Rust · Solidity

Levu & Roda

An exchange and the execution system beneath it.

My contribution to Levu spans a perpetual-futures exchange whose leverage limits follow measured liquidity, with oracle aggregation, margin allocation and a paper-trading interface. Roda supplies a deterministic Rust VM and a Go sequencer for each market.

Engineering notes

The execution layer includes checkpoint data availability and Solidity withdrawal verification. Roda is a development implementation; public-chain validity proofs are not yet deployed.
